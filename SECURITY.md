# Security policy

**Report a vulnerability privately** through GitHub security advisories: open this repository's **Security** tab
and choose **Report a vulnerability**. Do not open a public issue or pull request for it. Include what you found,
how to reproduce it, and the version or commit you tested.

Never paste tokens, API keys, login files, private keys or environment dumps into an issue, pull request or log
excerpt; if you did, revoke the credential first, then tell us.

The full policy, including which versions receive fixes, is [docs/security.md](docs/security.md). Every secret a
deployment can hold, where it is mounted and how to rotate it, is in [docs/secrets.md](docs/secrets.md).
