# UX sources

Every principle `standards/ux.md` rests on, traced to a primary source. `Sources:` lines in standards name these keys.
To revise a rule, read its keys here first: the source says what the evidence supports, and "How checked" says
whether a script can decide it or a reviewer must. "What it implies" is in our own words, from the primary source.
lawsofux.com is CC BY-NC-ND 4.0: only principle names, which are common terms, were used from it, as a map of
what to look up; no text, structure or adaptation was taken, and it appears as further reading only. **(verified)** marks a citation checked against Crossref or the source page; **(unverified)**
marks one that was not fetched. The register is wider than the rules: "none yet" means no rule cites the key.
