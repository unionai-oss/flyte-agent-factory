# brand

Applies only to visual or customer-facing deliverables: UI, docs sites, demos, reports and slides. Fill every bracketed placeholder for your organisation.

## BR-001 MUST
Fill in voice [VOICE], audience [AUDIENCE] and naming [NAMES] before publication.

Why: A template is not a brand decision.

Check: Search the deliverable brand source for unfilled bracket placeholders.

Enforced: judgement

## BR-002 SHOULD
Use the chosen voice consistently; do use plain verbs, do not use unexplained jargon.

Why: Readers need a consistent voice.

Check: Compare headings and representative paragraphs with the chosen voice examples.

Enforced: judgement

## BR-003 MUST
Define palette tokens [PRIMARY], [SURFACE], [TEXT] and meet WCAG AA contrast.

Why: Colour must remain readable.

Check: Measure text contrast: at least 4.5:1 normally and 3:1 for large text.

Enforced: judgement

## BR-004 SHOULD
Set typography [FONTS], [SCALE] and fallback fonts.

Why: Type hierarchy guides attention.

Check: Inspect computed fonts and heading sizes against the filled tokens.

Enforced: judgement

## BR-005 MUST
Use only approved logo [LOGO] with clear space [CLEAR_SPACE].

Why: Distorted marks confuse identity.

Check: Compare logo aspect ratio and surrounding space with the approved source.

Enforced: judgement

## BR-006 SHOULD
Use spacing scale [SPACING] and layout width [WIDTH].

Why: Consistent rhythm improves scanning.

Check: Inspect representative page spacing against the filled tokens.

Enforced: judgement

## BR-007 MUST
Use purposeful original imagery; do not use stock imagery.

Why: Visuals must explain this specific work.

Check: Inspect each image source and state its purpose.

Enforced: judgement

## BR-008 MUST
Label chart axes, units and sources and avoid misleading scales.

Why: Charts must support accurate comparisons.

Check: Inspect every chart for labels, provenance and an appropriate baseline.

Enforced: judgement

## BR-009 MUST
Support keyboard access, visible focus and meaningful text alternatives.

Why: Visual surfaces must work with assistive technology.

Check: Navigate all controls by keyboard and inspect image alternatives.

Enforced: judgement

## BR-010 SHOULD
Record do and do-not examples [EXAMPLES] for the chosen identity.

Why: Examples resolve ambiguous choices.

Check: Confirm the brand source includes one approved and one rejected example.

Enforced: judgement
